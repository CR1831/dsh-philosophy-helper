# dsh-philosophy-helper

哲学助手 —— 一个 DeepSeek Harness（DSH）插件。

它把哲学分析拆成十个可复用的引擎，配一个侧边栏面板、一张互动思维导图和一套导出工具。中西哲双轨，不以西方哲学为默认框架。

## 它解决什么问题

一般的聊天式哲学问答有三个毛病：结论来得太快、立场被压成漫画像、分析完就散在对话里找不回来。

这个插件把「一次哲学审议」当成一件有结构的工作来做：

- **先拆问题**，再问立场
- 每个引擎有固定输出格式，不给「这取决于你」这种滑头答案
- 结论写进案件库，可以回头查、并排比、导出去
- 硬性要求：结论之前先给反方最强版本

## 功能

**十个引擎**

| 引擎 | 干什么 |
|---|---|
| 概念澄清 | 歧义分叉、定义三件套、邻近概念对比 |
| 论证分析 | P–C 重构、隐含前提、谬误三级诊断、强度、反驳 |
| 立场比较 | 否定测试挖预设、五列立场表、价值排序 |
| 思想实验 | 变量枚举、单变量扰动、判别力检验 |
| 追问对话 | 一次一问，把张力摆出来 |
| 伦理审议 | 受影响者、权利冲突、四维评估 |
| 哲学史脉络 | 问题谱系、谁讨论过、阅读路线 |
| 写作辅助 | 提纲、反方意见、审稿十问 |
| 教学训练 | 学情、问题链、检查点 |
| 元层自省 | 依据标注、争议度、问题类型判定 |

**64 位哲学家方阵**（西方 56 / 中哲佛学 8），每位带文本锚点和「最易被误读成什么」，用于多子 Agent 的钢人化编排。

**侧边栏面板**，三个页签：案件 / 审议 / 资料。

**互动思维导图**：结构主义图版风格，三列对照（西哲 / 分析 / 中哲），正交折线，支持搜索、过滤、悬停预览。单文件 HTML，离线可开。

**导出**：Markdown 与单文件 HTML，正文渲染成真正的标题、列表、表格，而不是把源码塞进 `<pre>`。

**概念库**：跨案件复用概念拆解，同一个词自动合并义项。

**引文核对**：本地目录比对正文里出现的《…》，未收录的标出来，但明确说明「这不代表引错了」。

**自定义背景**：面板「资料」页可以选一张自己的图做侧边栏底图，存浏览器本地，不上传。

## 安装

需要 DSH 环境。在本目录下：

```bash
pnpm install --config.node-linker=hoisted
pnpm build
```

构建产物在 `lib/`。

把本目录作为本地插件加入 DSH profile（具体路径按你的 DSH 安装位置调整）：

```bash
dsh plugin add /path/to/dsh-philosophy-helper
```

然后在 DSH 的插件管理里启用。侧边栏会出现「哲学」图标。

### 开发

```bash
pnpm typecheck   # 类型检查
pnpm build       # 构建 host（ESM）与 client（CJS）
```

改完 host 侧代码需要重载插件，client 侧刷新页面即可。

## 用法

1. 侧边栏点「哲学」
2. 「审议」页输入问题，选模式（顾问 / 教练 / 评审 / 辩论）和立场
3. 点「开始分析」，插件会开一个专用会话跑引擎
4. 结果回到「案件」页，可以展开读、点「思维导图」、「导出」

面板和 agent 工具共享同一份案件记录，所以也可以在对话里直接让 agent 用 `philosophy_case_open` / `philosophy_case_save` 操作。

## 数据存在哪

全部在本地，不上传：

| 内容 | 位置 |
|---|---|
| 案件 | `~/.dsh/storages/philosophy-agent/cases.json` |
| 概念库 | `~/.dsh/storages/philosophy-agent/concepts.json` |
| 专用会话 | `~/.dsh/sessions/…/philosophy-<caseId>/` |
| 自定义背景 | 浏览器 `localStorage` |

删掉这些目录就等于清空记录。仓库里不含任何使用数据。

## 几个设计取舍

**为什么导出单文件 HTML**：成果锁在面板里等于不能交付。单文件可以离线打开、直接发人。

**为什么引文核对只说「未收录」**：误报比漏报更伤信任，尤其在中哲篇目上。本地清单是局部的，说「没收录」是事实，说「编造」是越界。

**为什么图注写数据不写排版**：图注该说「4 项分析，2 位西哲，2 位中哲」，不该说「问题在上、分析居中」——后者读者眼睛能看见。

**为什么不做多人协作**：DSH 是单机环境，没有账号体系。

## 已知限制

- 论点依赖图靠 `links` 字段，需要 agent 主动填；不填就只有「谁提到谁」
- 引文核对只比对本地约 110 本常见著作，超出范围的会标「未收录」
- 概念库不会自动从历史案件回溯填充，需要调用工具写入
- 思维导图超过约 20 个节点时，正交线会开始拥挤
