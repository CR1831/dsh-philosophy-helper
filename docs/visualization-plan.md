# 可视化方案

> 目标用户：哲学专业学生 + 无基础爱好者
> 状态：方案稿，未实施

---

## 一、两类用户缺的不是同一样东西

**无基础爱好者**卡在三个地方：

- 词不认识。「先验」「本体论」「他心问题」——每个词都要查，查到一半忘了自己在读什么
- 看不出好坏。两段论证读起来都挺有道理，凭什么说一方更强
- 读不下长文。一篇分析 2000 字，第三条和第四条对不上

**哲学专业学生**卡在另外三个地方：

- 论证骨架看不见。P–C 重构现在是文字列表，要自己在脑子里搭树
- 解释的分歧看不见。「康德主义者」和「康德本人」差在哪，表格说不清
- 训练没有反馈。写完了不知道哪里弱

**两者的交集**：都需要「把结构画出来」。但画法不同——爱好者要**入口**，专业学生要**骨架**。

已有的可视化：

| 图 | 面向 | 状态 |

**缺口**：所有图都是「案件级」的——告诉你这个案子跑了哪些分析。没有一张图是「论证级」的——告诉你这段论证长什么样。

## 三、八个方案

### 方案 1：论证结构图 ★★★★★

**解决**：专业学生最痛的一件事——看不见论证骨架。

**长什么样**：

```
        ┌─────────────┐
        │  P1 前提      │──┐
        │ estatistics  │  │
        └─────────────┘  │
                         ├──►┌─────────────┐
        ┌─────────────┐  │   │  C 结论      │
        │  P2 前提      │──┘   │ 把「我」整体 │
        └─────────────┘      │ 当项目违反   │
                             │ 目的公式     │
        ┌─────────────┐      └─────────────┘
        │  P3 隐含前提  │──────────┘
        │  （虚线框）    │   ↑ 单独标出
        └─────────────┘
```

**要点**：

- 前提、结论、**隐含前提**三种框，隐含前提用虚线框
- 攻击边画成红色虚线箭头，指向被攻击的具体前提——不是整体攻击
- 悬停任意节点，右边栏显示这个前提的原文出处

**需要的数据**：论证引擎输出结构化 `premises[]` / `conclusion` / `implicit[]` / `attacks[]`。

**成本**：中。契约改动 + 一种新布局（树形）。

---

### 方案 2：概念分叉树 ★★★★★

**解决**：爱好者最痛的一件事——一个词有四种意思，列表读不出「分叉感」。

**长什么样**：

```
                    变量
                     │
        ┌────────────┼────────────┐
        │            │            │
   统计变量      因果杠杆      控制参数
        │            │            │
   n>1 的样本    可干预+效应量   看可控性
        │            │            │
    ┌───┴───┐    ┌───┴───┐    ┌───┴───┐
  适用    失效   强    弱    可设  不可设
  多样本  单样本          如出生年代
```

**要点**：

- 一个词 → 四条路径，每条带判准
- 每条路径继续分叉：什么时候适用、什么时候失效
- 点任一条路径，右边栏出现例句和反例

**需要的数据**：概念引擎输出 `readings[] = { name, criterion, appliesWhen, failsWhen, example }`。

**成本**：中。契约改动 + 现有 SVG 渲染改造。

---

### 方案 3：立场坐标图 ★★★★

**解决**：读者读了一堆立场名字，不知道它们之间什么关系。

**长什么样**：

```
   自由意志
       ▲
       │    ● 萨特
       │
       │         ● 康德
       │
  ─────┼──────────────────► 决定论
       │
       │    ● 休谟
       │         ● 斯宾诺莎
```

**要点**：

- 两个轴由问题决定，不是固定轴（比如「自由 ↔ 决定论」× 「个体 ↔ 结构」）
- 每个哲学家一个点，点的大小 = 在该案件里的分量
- 悬停显示：他为什么在这个位置（一句话理由）
- 空白区域标出来：「这个象限没人——为什么」

第三点很重要。**位置图的空白比点更有信息量**。

**需要的数据**：立场引擎输出 `axisX` / `axisY` 的名称 + 每个立场的坐标与理由。

**成本**：中。布局简单，难在让 agent 诚实给坐标。

---

### 方案 4：反事实并排时间线 ★★★☆

**解决**：思想实验读起来像小说，看不出「只改了一个变量」。

**长什么样**：

```
现实：   ──●──●──●──●──►  2024
           │
         改了「要不要读研」

反事实： ──●──○──●──●──►  2024
              ↑
           这里分岔
```

**要点**：

- 现实和反事实两条平行线
- 分岔点高亮，只标**改动的那个变量**
- 每条线下方标该节点的代价与收益

**需要的数据**：反事实引擎输出 `baseline[]` / `counterfactual[]` / `pivot`。

**成本**：中低。

---

### 方案 5：谬误标注视图 ★★★★

**解决**：谬误诊断现在是列表，看不出「这句话在原文的哪个位置」。

**长什么样**：

```
原文：
> 康德说人不能被当作手段，所以把「我」当项目
> 是不道德的，因此追求效率的人都是坏人。

标注：
  ├─ [形式谬误] 「因此…都是」：从特称跳到全称
  ├─ [语用谬误] 引了康德却没给《奠基》页码
  └─ [未必是谬误] 「手段」在这里是日常义还是
                  目的公式里的义？两种读法结论不同
```

**要点**：

- 直接在原文上做**下划线标注**（像语法检查）
- 三种颜色：红（形式）/ 黄（语用）/ 灰（未必是，附解释）
- 点标注看详解

**关键**：第三类「未必是谬误」要用**灰色**，视觉上就弱于前两类。这比文字说明有效。

**需要的数据**：论证引擎输出 `marks[] = { span, level, reason }`。

**成本**：中高。要在原文里定位 span。

---

### 方案 6：哲学史时间轴 ★★★☆

**解决**：谱系引擎的「谁影响谁」是文字，看不出传承。

**长什么样**：

```
前 5 世纪        17 世纪         18 世纪         20 世纪
   │               │               │               │
 苏格拉底 ──► 笛卡尔 ──► 康德 ──► 胡塞尔
   │              │         │          │
  柏拉图 ────────┘         │       海德格尔
                            │          │
                          黑格尔 ──► 萨特
```

**要点**：

- 横轴是时间，纵轴是思想谱系（避免箭头交叉）
- 箭头 = 影响关系，虚实区分「直接师承」和「间接影响」
- 中国哲学单独一条轨道，**和西方并行**，不塞进同一条时间轴

最后一点是硬要求。中西不是同一条时间线的两端。

**需要的数据**：谱系引擎输出 `nodes[] = { name, year, tradition }` / `links[] = { from, to, kind }`。

**成本**：中。

### 方案 7：术语悬浮卡 ★★★★

**解决**：爱好者读三步要查两次词。

**长什么样**：

```
分析正文：
「康德的**目的公式**要求……」

        ┌──────────────────┐
        │ 目的公式           │
        │ ────────────────  │
        │ 把人性的东西始终    │
        │ 同时当作目的，绝不 │
        │ 仅仅当作手段。      │
        │                   │
        │ 出自《道德形而上学  │
        │ 奠基》第二章        │
        │                   │
        │ [这是康德自己的用法] │
        └──────────────────┘
```

**要点**：

- 正文里识别出的术语加虚线下划线
- 悬停/点击弹出卡片，不是跳页
- 卡片底部标：这是**通说**还是**该哲学家自己的用法**——两者常冲突

**需要的数据**：一份术语表（可先用 200 个常用词起步），挂到 persona 和引擎输出上。

**成本**：低。不需要改引擎，只加一层识别 + 卡片。

---

### 方案 8：伦理审议影响矩阵 ★★☆

**解决**：受影响者、权利冲突、代价现在是三段文字。

**长什么样**：

```
            知情    自主    不伤害    公平
当事人 A    ✓       ✓       ⚠        ✓
当事人 B    ✗       ✓       ⚠        ✗
第三方      ✓       —       ✓        ⚠

⚠ = 有冲突，点开看冲突在哪
```

**要点**：

- 行是受影响者，列是权利维度
- 单元格三种态：满足 / 冲突 / 不适用
- 点冲突格看「谁的什么权利被谁的什么权利压过」

**成本**：低。表格渲染已有。

## 四、优先级

按「价值 / 成本」排：

| 顺序 | 方案 | 面向 | 成本 | 理由 |
|---|---|---|---|---|
| 1 | 术语悬浮卡 | 爱好者 | 低 | 不用改引擎，立刻降门槛 |
| 2 | 论证结构图 | 学生 | 中 | 最高价值，专业学生刚需 |
| 3 | 概念分叉树 | 爱好者 | 中 | 改造现有渲染，复用率高 |
| 4 | 谬误标注视图 | 学生 | 中高 | 视觉上「灰色第三类」很关键 |
| 5 | 立场坐标图 | 两者 | 中 | 空白区域的信息量最大 |
| 6 | 哲学史时间轴 | 两者 | 中 | 中西双轨必须并行 |
| 7 | 反事实时间线 | 爱好者 | 中低 | 场景窄 |
| 8 | 伦理影响矩阵 | 学生 | 低 | 表格已能承载 |

## 五、不该做的

**3D 图谱 / 力导向弹簧图**：好看，但读不出结构。哲学图的核心是「位置有意义」，弹簧图的位置是算法生成的，没有意义。

**词云**：出现频率不等于重要性。「存在」出现 50 次，可能只是作者口头禅。

**动画过渡**：切图时飞入飞出，看第一次新鲜，看第二次烦。

**「理解度评分」**：给爱好者打「你已理解 73%」这种分，是假的。没有可靠的测量方式，做了就是骗人。

**自动摘要图**：把 2000 字压成三个关键词，看起来省事，实际上把论证的转折全丢了。

## 六、一个前提

上面八个方案里，**有五个需要引擎输出结构化数据**（方案 1、2、3、4、5）。

现在的引擎输出是自由 Markdown，图只能从文本里用正则猜。猜到的东西不可靠——思维导图现在的「谁提到谁」就是这么来的，它只能告诉你「这两个词出现在同一段」，不能告诉你「这个论证在反驳那个」。

所以真正的第一步不是画图，是**改引擎契约**：让 `philosophy_case_save` 除了 `body` 之外，再收一个 `graph` 字段，结构由引擎类型决定。

```ts
{
  engine: "argument",
  body: "…（给人读的 Markdown）…",
  graph: {                       // 给图用的结构
    premises: [{ id: "p1", text: "…", implicit: false }],
    conclusion: { id: "c", text: "…" },
    supports: [["p1","c"], ["p2","c"]],
    attacks: [{ from: "p3", to: "p1", kind: "premise" }]
  }
}
```

这一步做完，后面每种图都只是「换一个渲染器」。

不做这一步，图看着热闹，线是猜的。
